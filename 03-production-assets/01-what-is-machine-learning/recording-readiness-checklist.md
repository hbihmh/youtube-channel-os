# ML-01 — Recording Readiness Checklist

**Lecture:** ML-01 — What Is Machine Learning?  
**Phase:** 4I-8 — Recording Readiness  
**Status:** Preparation checklist

Use this checklist immediately before the first recording session. Check every applicable item; do not mark an item complete from assumption.

## B. Script Lock

## C. Scope Lock

Confirm that recording does **not** teach:

- [ ] Derivatives
- [ ] Gradients
- [ ] Loss functions
- [ ] Gradient descent
- [ ] Optimization mathematics
- [ ] Optimization landscapes
- [ ] Linear regression mathematics
- [ ] Logistic regression
- [ ] Detailed overfitting mechanisms
- [ ] Detailed bias/variance analysis
- [ ] Python implementation as a technical lesson

If any of these appear beyond a brief deferred-topic reference, stop and correct the recording plan before proceeding.

## J. Recording Authorization

### Status options

**BLOCKED** — one or more critical readiness items are incomplete.  
**READY** — all applicable critical items are verified.  
**RECORDING** — session has started.

### Critical blockers

Do not start recording if any of the following remains unresolved:

- Script version is uncertain.
- Core visual is missing or incorrect.
- Code demo fails.
- Audio test fails.
- Recording software is not functioning.
- A scope violation remains in the planned narration/visuals.
- A material factual claim is unresolved.
- Storage/file handling is not ready.
