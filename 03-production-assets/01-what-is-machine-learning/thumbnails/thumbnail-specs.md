# ML-01 Thumbnail Specifications

## Concept 1: Traditional vs. Machine Learning Paradigm
- Visual Focus: Split layout contrasting static hardcoded IF/ELSE rules against a trained weight/parameter structure.
- Text Overlay: 'Rules vs. Learned Parameters' or 'How Computers Actually Learn'.
- Color Palette: High-contrast dark background with clean architectural white/cyan text to match channel branding.

## Concept 2: The Core Mental Model
- Visual Focus: Flow from Data -> Learning Algorithm -> Model -> Prediction.
- Text Overlay: 'Machine Learning From First Principles'.
- Design Rule: Avoid clutter; single focal point on the core feedback/learning pipeline.
