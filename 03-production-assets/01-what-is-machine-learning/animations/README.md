# Animations & Motion Guidelines - ML-01

This directory documents the animation strategy for lecture ML-01 supporting visuals and core diagrams.

## Principles
1. **Motion Explains, Not Decorates:** Animations are strictly used to clarify sequential flows (e.g., Data → Learning Procedure → Model).
2. **Independent Elements:** All SVG nodes (boxes, arrows, text layers) are structured for independent opacity or translation adjustments during video editing.

## Recommended Editing Order / Sequences
- **Core Mental Model & Learning Flow:** Fade in historical examples, reveal learning procedure, slide in trained model, then reveal new unseen input and prediction.
- **Traditional vs. ML:** Compare sequential blocks side-by-side.
- **Transitions:** Use `ml-02-transition.svg` as a clean closing bridge to the next module.
