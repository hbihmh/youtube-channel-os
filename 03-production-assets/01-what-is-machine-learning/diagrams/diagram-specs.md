# ML-01 Diagram Specifications

## 1. Core ML Mental Model
[Data / Experience] -> [Learning Procedure] -> [Model] -> [Prediction]

## 2. Traditional vs ML
Traditional: Input + Explicit Rules -> Output
Machine Learning: Examples -> Learning -> Model -> Prediction

## 3. Training vs Inference
Training: Training Data -> Learning Algorithm -> Trained Model
Inference: New Unseen Data + Trained Model -> Prediction

## 4. Supervised Learning Paradigm
Features (Input) + Labels (Target) -> Learning Algorithm -> Model

## 5. Generalization Concept
Training Examples -> Model -> High Performance on Unseen Data

## 6. Spam Classifier Example
Spam/Not Spam Examples -> Learning Algorithm -> Threshold Model -> New Message Classification
