\# Source Selection Rules



\## Rule 1 — Primary sources establish historical claims



Use S01 when discussing the historical development of machine learning.



Do not use it as the sole authority for modern terminology.



\---



\## Rule 2 — Academic textbooks establish foundational concepts



Use S02–S04 for core conceptual explanations.



\---



\## Rule 3 — Never cite a source merely because it contains the keyword



A source must actually support the claim being made.



\---



\## Rule 4 — One claim may have multiple supporting sources



For important claims:



Primary source

\+

Academic cross-check



is preferable to:



Five random websites.



\---



\## Rule 5 — Secondary sources are not required yet



Do not add blogs, Medium articles, Reddit posts, or random tutorials unless

they provide something genuinely useful that the primary/academic sources

do not.
