\# Machine Learning From First Principles

\# Season 1 Curriculum Roadmap



\## Purpose



This document defines the educational architecture of Season 1:



> Machine Learning From First Principles



The season is designed to take a learner from basic machine learning

vocabulary to implementing and evaluating fundamental machine learning

algorithms without relying on high-level machine learning abstractions.



The curriculum emphasizes:



\- Conceptual understanding

\- Mathematical reasoning

\- Algorithmic thinking

\- Python implementation

\- Controlled experimentation

\- Model evaluation

\- Limitations and assumptions



\---



\# 1. Season Promise



By the end of Season 1, a learner should be able to explain and implement

the fundamental learning process behind classical machine learning models.



The learner should understand not only:



> "How do I use this model?"



but:



> "Why does this model work, what mathematics makes it work, how is it

> implemented, how can I test it, and where does it fail?"



\---



\# 2. Target Learner



Primary audience:



\- BSCS students

\- Computer science students

\- Serious self-learners

\- Beginner-to-intermediate programmers

\- Learners interested in AI/ML fundamentals



Expected background:



\- Basic Python

\- Basic programming logic

\- Basic algebra

\- Willingness to learn calculus and mathematical notation



The curriculum does NOT assume advanced machine learning knowledge.
